🎮 Tic-Tac-Toe

Este projeto nasceu em 2024, quando eu ainda estava finalizando o ensino médio. Na época, eu queria testar minhas habilidades na prática, então decidi criar um jogo da velha — simples na ideia, mas cheio de oportunidades pra aprender. Durante o desenvolvimento, o projeto foi evoluindo muito mais do que eu imaginava. O que começou como um desafio pessoal acabou se tornando um dos períodos mais produtivos (e divertidos) que já tive. Passei boa parte das férias estudando, testando ideias e pesquisando qual tecnologia faria mais sentido usar. Cheguei a considerar algumas opções como HTML, CSS e JavaScript, além da Godot Engine em 2D. No final, optei por usar a Unity com C#, principalmente por já ter uma base maior nessas ferramentas. Mesmo assim, foi um processo de bastante aprendizado: precisei estudar novos conceitos, testar diferentes abordagens e refatorar o código várias vezes até chegar em uma versão estável e jogável.Mais do que o resultado final, esse projeto foi importante pela experiência.
